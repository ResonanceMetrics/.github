# ResonanceMetrics

**GEO visibility platform: measure and improve how your brand appears in AI engines such as ChatGPT, Claude, Gemini, Perplexity and Google AI Overviews.**

ResonanceMetrics combines technical GEO audits and AI answer tracking for e-commerce brands and agencies, in French, English, Spanish and German.

## What you'll find here

- **MCP server guide**: connect the read-only ResonanceMetrics MCP server from Claude and other agents to get visibility, cited sources, recommendations and activity reports in your assistant (Advanced plan). See the [MCP guide](https://www.resonancemetrics.com/en/mcp).
